## 1. 화면 구성도 (클라우드)

```
┌─ [인증 게이트] API 키 입력 / 로그인 ← 신규 필수 (무인증 공개 금지) ─┐
└────────────────────────┬───────────────────────────────────────┘
                         ▼  (X-API-Key 헤더 주입)
┌─ Header (sticky) ─ AI Composer | [Provider ▾] | session badge ─┐
│  ┌─ Page 1: 기획 (#pagePlan, max 580px) ─┐                      │
│  │  트랙 기획 폼 → [트랙 생성]              │                      │
│  │  └ 제안 결과 → [🎼 생성 시작][🎚 스템 분리]│                      │
│  └──────────────────────────────────────┘                      │
│  ┌─ Page 2: DAW (#pageDaw, max 1100px) ──┐                      │
│  │  [새 기획][기획 수정][믹스 만들기] ⬇mp3   │                      │
│  │  트랙행 × N (정보 | 파형 | 컨트롤)        │                      │
│  └──────────────────────────────────────┘                      │
│        모달: 기획 수정 (#modal, overlay)                          │
└─────────────────────────────────────────────────────────────────┘
```

> ⚠️ **신규 과제:** 현재 프론트(`index.html`)는 `X-API-Key` 헤더 미주입, 인증 화면 없음.
> 클라우드 공개 노출 시 (1) 인증 게이트 화면 + (2) 모든 `api()` 호출에 키 헤더 주입 추가 필요(기획 §3·§6-2).

## 3. Page 1 — 기획 입력

### 3-1. 폼 (`#planForm`)
| 필드 | name | 타입 | 제약 |
|------|------|------|------|
| 장르 | genre | text | required |
| 분위기 | mood | text | required |
| BPM | bpm | number | 40~240, auto |
| Key | key | text | auto |
| 길이(초) | duration | number | 5~600, 기본30 |
| 추가 지시 | prompt | textarea | — |

### 3-2. 제안 결과 (`#planResult`)
- 메타: `{bpm} bpm · {key} · {N} tracks`.
- `🎼 생성 시작` → `/generate/all`, `🎚 스템 분리` → `/generate/separated`.
- ⚠️ 진행률 SSE: 모바일 백그라운드 전환 시 끊김 → 재연결 + `/session/{id}` 복원 필요(기획 §6-6).

## 6. 상태 전이 (멀티 기기)

```
[인증] API 키/로그인 → 헤더 주입
[최초] session 없음 → Page 1
[타 기기 재접속] session_id → /session/{id} ─ 200 → Page 2 복원 / 401 → 인증 재요구 / 만료 → Page 1
Page 1 ─ /plan → 제안 ─ 생성(SSE) → Page 2
```

### SSE → UI (`readStream()`)
| 이벤트 | UI |
|--------|-----|
| `queue` | 대기 메시지 |
| `percent` | 바 + `{track_name} {percent}%` |
| `done`(done/partial/error) | 완료 / 일부 실패 / 전부 실패 |
| `error` | "⚠ {message}" |
| `provider_switched` | 전환 완료 |

> cold start(모델 C): 첫 생성 시 "웜업 중(수십초~분)" 표시 필요(기획 §3·§6-5).

## 8. 모바일 / PWA 과제 (클라우드 핵심, 기획 §6-6)

현 `index.html`은 데스크톱 폭 가정. 클라우드 = 임의 기기 접속 → 보강 필수.

| 항목 | 현재 | 클라우드 보강 |
|------|------|--------------|
| 레이아웃 | `@media(max-width:700px)` 트랙 1열만 | 반응형 점검·터치 타깃 확대·뷰포트 |
| 설치감 | 브라우저 | (선택) PWA — manifest + service worker, "홈 화면 추가" |
| SSE | 동작 | 모바일 백그라운드 전환 재연결 + 세션 복원 |
| 인증 | 없음 | 인증 게이트 화면 + 키 헤더 주입 |
| 접속 | — | `https://<도메인>` HTTPS, 인증서 유효 |

> 범위(기획 §12 결정 6): 1차 반응형, 2차 PWA. 네이티브 앱은 비목표.
