## 3. Page 1 — 기획 입력

### 3-1. 폼 (`#planForm`)
| 필드 | name | 타입 | 제약 |
|------|------|------|------|
| 장르 | genre | text | required |
| 분위기 | mood | text | required |
| BPM | bpm | number | 40~240, 빈값=auto |
| Key | key | text | 빈값=auto |
| 길이(초) | duration | number | 5~600, 기본30 |
| 추가 지시 | prompt | textarea | — |

제출 → `submitPlan()`. 로딩바 `planLoading` + 상태 `planStatus`.

### 3-2. 제안 결과 (`#planResult`)
- 메타: `{bpm} bpm · {key} · {N} tracks`.
- 트랙 리스트: `{order}. {name} / {instrument}` + caption.
- `🎼 생성 시작` → `/generate/all` → DAW 전환.
- `🎚 스템 분리 생성 (Demucs)` → `/generate/separated` → DAW 전환.
- 진행률 `progressBar1` / `progressText1`.

## 4. Page 2 — DAW 편집

### 4-1. 헤더 버튼
| 버튼 | ID | 동작 |
|------|-----|------|
| 새 기획 | `newSessionBtn` | confirm → 세션 클리어 → Page 1 |
| 기획 수정 | `editPlanBtn` | 모달 open |
| 믹스 만들기 | `mixBtn` | `/mix/{id}` → mp3 링크 |
| mp3 다운로드 | `mixLink` | `⬇ mix_v{N}.mp3` |

### 4-2. 트랙 행 (3열 그리드 `170px 1fr 200px`)
| 열 | 내용 |
|----|------|
| 정보 | `{order}. {name}` / instrument |
| 파형 | `<canvas>` — `/waveform` peaks → `drawWave()` |
| 컨트롤 | audio / 볼륨 슬라이더(0~2) / [재생성][Repaint ▾] / Repaint 폼 |

- `wav_url` 없으면 "생성 전".
- 볼륨 input → `/track/{id}/{order}/volume` 즉시 저장.
- 재생성 → `/generate/track` SSE → 재렌더.
- Repaint: 시작/끝(s) → `/repaint`, `end≤start` alert 차단.

### 4-3. 파형
`drawWave(canvas, peaks)` — Canvas 2D, dpr 보정, accent 세로선.

## 6. 상태 전이

```
[최초] session 없음 → Page 1
[재방문] localStorage → /session/{id} ─ 200 → Page 2 / 만료 → clear → Page 1
Page 1 ─ /plan → 제안 ─ 생성 → Page 2
Page 2 ─ 새 기획 → Page 1 / 기획 수정 → 모달 → Page 2
```

### SSE → UI (`readStream()`)
| 이벤트 | UI |
|--------|-----|
| `queue` | 대기 메시지 |
| `percent` | 바 + `{track_name} {percent}%` |
| `done`(done) | "완료" |
| `done`(partial) | "일부 실패" (적색) |
| `done`(error) | "⚠ 모든 트랙 실패" (적색) |
| `error` | "⚠ {message}" (적색) |
| `provider_switched` | 전환 완료 |
