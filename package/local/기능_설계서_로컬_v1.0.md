## 1. 기능 개요

기획 입력 → 트랙 자동 생성 → DAW 편집 → 믹스 다운로드. 무거운 연산(ACE-Step 생성,
Demucs 분리)은 단일 워커 큐로 직렬화하여 GPU OOM 방지. 전 연산은 **사용자 PC GPU**에서 수행.

| 영역 | 핵심 기능 |
|------|----------|
| 기획 | 장르·분위기·BPM·Key·길이·추가지시 → AI 트랙 목록 + 캡션 |
| 생성 | 전체 생성(순차) / 스템 분리 생성(곡 1개 → Demucs) |
| 편집 | 재생성 · Repaint · 볼륨 · 잠금/오버라이드 |
| 믹스 | pydub 볼륨 믹싱 → WAV/MP3, 버전 관리(최대 10) |
| 세션 | localStorage 복원, TTL 24h 자동 정리 |
| Provider | Ollama(기본)·Claude·OpenAI·Gemini 런타임 교체 |

## 3. 핵심 기능 상세

### 3-1. 트랙 기획 (`/plan`)
- 입력: genre(필수)·mood(필수)·bpm(40~240/auto)·key(auto)·duration(5~600s)·prompt.
- `factory.get_provider().plan_tracks()` → 트랙·캡션·BPM·Key. 실패 시 502, DB 실패 500.
- `session_id`(uuid hex) 즉시 발급 → 세션·트랙 기록.
- 캡션 규칙(`prompt_builder.build_caption()`):
  ```
  bpm = bpm_override if (locked == 0 and bpm_override) else global_bpm
  key = key_override if (locked == 0 and key_override) else global_key
  caption = f"{caption}, {bpm} bpm, {key}, no vocals"
  ```

### 3-2. 전체 생성 (HEAVY)
- 트랙별 ACE-Step text2music 순차 → `track_N.wav` → `wav_url` 갱신.
- SSE: `queue` → `percent` → `done`(done/partial/error).

### 3-3. 스템 분리 생성 (HEAVY)
- 곡 1개 생성 → `_source.wav` → Demucs(htdemucs) → drums/bass/other.
- `clear_tracks()` 후 스템 교체(`db.py:171`). 로컬 GPU VRAM 직렬 점유.

### 3-4. 편집 (LIGHT)
| 기능 | 경로 | 동작 |
|------|------|------|
| 재생성 | `/generate/track/{id}/{order}` | 단일 트랙 재호출 |
| Repaint | `/repaint` | `end>start` 검증 후 구간만, WAV in-place |
| 볼륨 | `.../volume` | `tracks.volume` 갱신 |
| 잠금 | `.../lock` | `locked` + override |

### 3-5. 믹스
- pydub 볼륨 합성 → `mix_vN.wav` + MP3. `MAX_MIX_VERSIONS=10` 초과 시 oldest 파일+행 삭제.

### 3-6. 세션
- 프론트 `localStorage["session_id"]` → 재방문 `/session/{id}` 복원.
- 백엔드 `SESSION_TTL_HOURS=24` APScheduler 정리.

### 3-7. Provider 교체 (LIGHT)
- `factory.switch_provider()` + `db.update_all_sessions_provider()`. 큐 경유 → 생성 중 인터럽트 불가.

## 4. 큐 / 동시성

```
브라우저 → FastAPI :8080 → asyncio.PriorityQueue (단일 워커) → ACE-Step :8001 / Demucs / mixer
```

| 우선순위 | 값 | 작업 | 순서 |
|---------|----|------|------|
| HEAVY | 0 | 전체 생성, 스템 분리 | **먼저** |
| LIGHT | 1 | 재생성, Repaint, Provider 교체 | 나중 |

> Python PriorityQueue 숫자 낮을수록 먼저 → HEAVY(0) 우선. 단일 워커 = 로컬 GPU(6GB 공유) OOM 방지.

## 5. 로컬 배포 특성

| 항목 | 값 | 근거 |
|------|-----|------|
| 접속 | `http://localhost:8080` | 기획 §13-1 |
| 바인딩 | `--host 127.0.0.1` (LAN 차단) | 기획 §6-9 |
| 인증 | **무인증 허용**(단일 사용자 전제) | `config.py:59` |
| ACE-Step | `localhost:8001`, `uv run acestep-api` | 기획 §6-3 |
| 데이터 경로 | `%LOCALAPPDATA%\AI Composer\` (Program Files 쓰기 제한 분리) | 기획 §5 |
| Provider | Ollama 기본(로컬 무료) | `.env` |

> ⚠️ 보안: `require_api_key`는 `API_KEY` 미설정 시 통과. 로컬 단일 사용자는 127.0.0.1 바인딩이 전제 유지.
> 원격 접근 허용 시 반드시 `API_KEY` 설정(기획 §6-9).

## 6. 에러 처리

| 상황 | 코드 | 처리 |
|------|------|------|
| Provider 실패 | 502 | `AI provider failed` |
| DB 실패 | 500 | `DB error` |
| 세션 없음 | 404 | `Session not found` |
| Repaint 구간 오류 | 400 | `end_sec must be greater than start_sec` |
| 파형 소스 없음 | 404 | `Waveform source not found` |
| 생성 부분 실패 | SSE | `done.status=partial` |
| 생성 전부 실패 | SSE | `done.status=error` |
